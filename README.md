# Cursor Processing Robot

A Three.js + Vite interactive robot inspired by the supplied reference image.

## Features

- Stylized metallic black/purple robot
- Cursor-following head and eye direction
- Cursor distance and processing HUD
- Processing/scanning states
- Particle trail around the cursor
- Animated black-hole style background
- Responsive rendering
- Frame-rate-independent movement using delta time
- Resolution-aware particle/star count

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
